## Run locally

```bash
git clone https://github.com/Vaibhavpandey-web/html-website.git
cd html-website
python -m http.server 8080
```

Open [localhost:8080](http://localhost:8080). External libraries and assets require an internet connection.

<details>
<summary><strong>Editing and deployment</strong></summary>

Page styles and interactions are embedded in the HTML files. Images are stored in the repository root. Preserve filename capitalization when changing asset references, especially on case-sensitive hosting.

Deploy the root folder to a static host. No package installation or build step is required. Company names, logos and photography remain the property of their respective owners.

</details>
